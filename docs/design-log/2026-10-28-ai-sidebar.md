# 이미지 라이브러리 옆 AI 채팅

대상은 로컬 이미지 목록을 보며 참조를 선택하고 새 이미지를 만드는 사용자다. 컨셉은 “이미지 탐색을 유지하는 macOS 네이티브 보조 채팅”이다.

사용자가 지정한 같은 워크스페이스 jena-note의 AIChatViewController, AIChatTranscriptView, AISettingsViewController와 ai-chat-layout 기록을 기준으로 했다. 일반 웹 레퍼런스를 섞지 않고 기존 AppKit 폰트·시스템 색·버튼을 사용한다.

- 오른쪽 가변 폭 패널: 기본 300, 최소 280, 최대 600pt. 중앙 목록/뷰어는 유지한다.
- 상단 제목·설정·닫기, 현재 자동 저장 폴더, 스크롤 대화, 첨부 썸네일, 입력창, 전송·중지 순서.
- 내 메시지는 오른쪽 회색 말풍선, 결과는 왼쪽 이미지와 저장 위치, 오류는 별도 상태 메시지.
- 썸네일의 제거 버튼에는 파일명을 포함한 접근성 이름을 부여한다.
- 폴더가 없으면 저장 위치 안내와 비활성 전송 버튼으로 원인을 설명한다.
- 설정 탭은 상태에 해당하는 설치/로그인 액션만 보이고 재확인은 유지한다.

## 하단 입력부 통합 (사용자 제공 대화 샘플 반영)
- 대화 스크롤 영역과 clip view는 투명하게 두어 패널 전체가 한 바탕색으로 이어진다.
- 입력부만 둥근 배경으로 은은하게 구분한다. 상단에는 제목과 닫기만 남긴다.
- 입력창 안에 + 이미지 추가, ⋯ 자동 저장 정보/연결 설정, 생성 중 진행/중지 아이콘을 둔다. 입력창 안 아래 도구 줄에 모델 선택을 함께 둔다. 모델 목록은 Codex CLI에서 조회하며 음성 라이브는 추가하지 않는다.
- 입력창 바깥 전송 버튼과 설명 라벨을 제거하고 안내는 placeholder와 접근성 도움말로 제공한다. Enter 전송, Shift+Enter 개행, IME 조합 중 전송 방지.
- 첨부는 입력창 위 가로 목록. 텍스트 입력부는 32~128pt로 늘어나고 이후 스크롤한다.

- 헤더 겹침 수정: 채팅의 상단 제목/닫기는 창의 safe area 아래 14pt에서 시작한다. fullSizeContentView 배경은 유지하며 툴바 높이에 맞춰 자동으로 내려간다.
