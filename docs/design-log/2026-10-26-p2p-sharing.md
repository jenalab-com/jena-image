- Core user emotion: 파일을 안전하게 주고받는다는 통제감과 신뢰
- Space axis: Urban

- Texture level: 1

- AX-SK: 0/5 · AX-JP: 5/5 · AX-MN: 5/5 · AX-MU: 0/5 · AX-AN: 1/5 · AX-BQ: 0/5

- Key scene keyword: 로컬 라이브러리와 구분되는 조용한 네트워크 목록
- Most critical feature: 공유 폴더 발견과 선택 이미지 다운로드

## 결정

- 기존 사이드바 아래에 `네트워크 공유` 섹션을 분리한다. 로컬 폴더와 같은 트리 노드로 위장하지 않는다.
- 원격 콘텐츠는 기존 이미지 카드와 격자를 계승하되 상단에 공유자·이미지 수·`읽기 전용`을 고정 표시한다.
- 다운로드만 primary action으로 두고 편집·삭제·이동·업로드는 제공하지 않는다.
- 색과 장식보다 연결 상태, 진행률, 실패 상태의 문자 정보와 아이콘을 우선한다.
- 기존 AppKit source-list·카드·시스템 폰트를 재사용해 새로운 시각 언어를 만들지 않는다.

## 검토한 대안과 트레이드오프

- 원격 폴더를 기존 로컬 트리에 혼합: 탐색은 단순하지만 원격/로컬 작업을 혼동하기 쉬워 별도 섹션을 선택했다.
- 원격 항목도 기존 뷰어로 즉시 열기: 캐시·읽기 전용 상태·비동기 탐색 변경이 커 MVP는 썸네일과 다운로드에 집중했다.
- 별도 공유 창: 기존 코드 침습은 적지만 사이드바에서 공유 목록을 본다는 요구와 맞지 않아 메인 창 통합을 선택했다.
- 장식적 네트워크 상태 표현: P2P 분위기를 낼 수 있지만 생산성 화면의 정보 명확성보다 우선하지 않았다.
