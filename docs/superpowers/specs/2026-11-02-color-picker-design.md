# 색상 추출·돋보기 — 설계

> 상태: **승인됨 (2026-11-02).** 브레인스토밍 기록(`2026-11-02-color-picker-brainstorm.md`)의 결정을 정리한 설계 문서다.
> 시안: `docs/superpowers/mockups/2026-11-02-color-palette-placement.html`(패널 위치, A안), `docs/superpowers/mockups/2026-11-02-color-magnifier-style.html`(돋보기, ③안)

## 1. 목적

드로잉 툴(포토샵·페인터·클립스튜디오·일러스트레이터)로 그림을 그리다가, jena-image에서 참고 이미지를 열어 마음에 드는 색을 **다른 툴의 스포이드를 띄우지 않고 바로 확인하고 가져가기** 위한 기능이다.

두 가지로 이뤄진다.

- **컬러칩**: 이미지 전체에서 색을 뽑아 비율 순 칩으로 보여주고, 값을 복사한다.
- **돋보기**: 커서 아래 픽셀의 색을 확대해 보여주고, 클릭하면 값을 복사한다.

## 2. 범위

| 포함 | 제외(다음 단계) |
|---|---|
| 상세 화면의 색상 버튼, 하단 색상 패널 | 비교 화면(`ComparePaneView`)에서의 색상 기능 |
| 허용 범위 슬라이더와 실시간 칩 재계산 | 이미지별 추출 결과 저장 |
| 칩 정보창(HEX·RGB·CMYK) 및 복사 | 팔레트 파일 내보내기(`.ase` 등) |
| "HEX 전체 복사" | 칩 고정 선택, 돋보기로 고른 색을 칩에 추가 |
| 돋보기(토글 + ⌥ 임시) 및 클릭 복사 | ICC 프로파일 기반 CMYK |
| AI 컬러 시스템이 쓸 추출 결과 데이터 구조 | AI 컬러 시스템 자체 |

## 3. 화면과 동작

### 3.1 색상 버튼

- 위치: 하단 버튼 줄 `[카테고리][북마크][색상][편집][썸네일 토글]` — 편집 버튼 왼쪽.
- 토글 버튼. 켜면 색상 패널이 열리고, 끄면 닫힌다.
- 활성 조건은 편집 버튼과 같다: **동영상이면 숨김, 원본 로딩이 끝난 뒤에만 활성.** 썸네일 미리보기 상태에서 뽑으면 저해상도 값이 나오기 때문이다.
- 패널이 열린 채 다른 이미지로 넘어가면 패널은 유지하고, 새 원본 로딩이 끝나면 다시 추출한다. 로딩 중에는 칩 영역을 비우고 로딩 표시를 한다.

### 3.2 색상 패널(하단 서랍)

이미지 아래에서 올라오며, 이미지 영역이 그만큼 줄어든다(이미지를 가리지 않음).

```
┌──────────────────────────────────────────────────────────────┐
│ [🔍]  범위 ────●──────── 14색                 [HEX 전체 복사] │
│ ┌────────────┐                                                │
│ │■ 커서 위치 색│  ■ ■ ■ ■ ■ ■ ■ ■ ■ ■ ...                       │
│ │HEX  #E76F51│  23% 18% 15% 11% ...                           │
│ │RGB  231,…  │                                                │
│ │CMYK 0,52,… │                                                │
│ └────────────┘                                                │
└──────────────────────────────────────────────────────────────┘
```

- **돋보기 토글 아이콘** `[🔍]`: 돋보기를 켜고 끈다.
- **허용 범위 슬라이더**: 움직이면 칩 개수가 실시간으로 늘고 준다. 값은 앱 전체에서 마지막 값을 기억한다(`AppSettings`).
- **"커서 위치 색" 칸**: 돋보기가 켜져 있을 때 커서 아래 색의 HEX·RGB·CMYK를 보여준다. 커서가 이미지 밖에 있으면 마지막으로 클릭한 색을 보여주며, 값마다 복사 버튼이 있다. 돋보기가 꺼져 있으면 숨긴다.
- **칩 목록**: 차지 비율 순으로 놓고 비율(%)을 칩 아래 표시한다. 넘치면 줄바꿈한다.
- **"HEX 전체 복사"**: 칩 색을 비율 순서대로 공백으로 구분해 복사한다(`#3F7CAC #E9C46A …`).

### 3.3 칩

| 동작 | 결과 |
|---|---|
| 마우스 오버 | 칩 **위쪽에 붙여** 정보창을 띄운다: 색 견본, HEX·RGB·CMYK, 값마다 복사 버튼. 커서가 칩 또는 정보창 위에 있는 동안 유지한다(칩에서 정보창으로 옮겨가도 닫히지 않음). 정보창이 옆 칩을 가리지 않게 배치한다. |
| 클릭 | HEX를 즉시 복사한다. 정보창은 유지하고 HEX 줄에 "복사됨"을 약 1초 표시한다. |

### 3.4 돋보기

**표시(③안)**

- 커서 옆에 작은 원형 확대경(픽셀 격자, 가운데 읽는 픽셀을 흰 테두리로 강조)과 HEX 한 줄 라벨이 따라다닌다.
- 전체 값(HEX·RGB·CMYK)은 패널의 "커서 위치 색" 칸에 보여준다.
- 커서가 창 가장자리에 가까우면 확대경을 반대편으로 뒤집어 배치한다.
- 이미지 밖 여백이나 패널 위에서는 확대경을 숨긴다. 커서는 이미지 위에서 십자 모양이다.

**켜기**

- 패널의 돋보기 토글로 켜고 끈다. 패널을 연다고 자동으로 켜지지 않는다.
- 패널을 닫으면 돋보기도 꺼지고, 다시 열면 꺼진 상태로 시작한다. 패널이 열린 채 다른 이미지로 넘어가면 켜진 상태를 유지한다.
- **⌥를 누르고 있는 동안** 임시로 켜진다.
  - 패널이 닫혀 있어도 동작한다. 이때는 확대경과 HEX 한 줄만 보이고, 클릭하면 HEX를 복사한다.
  - 원본 로딩이 끝난 이미지에서만 동작한다(동영상 제외).
  - **⌥ 단독**일 때만 켠다. ⌘⌥ 같은 조합 키를 누를 때는 켜지 않는다.
  - 토글이 이미 켜져 있으면 ⌥는 아무 변화가 없다(켜기만 하고 끄지는 않는다).

**돋보기가 켜진 동안 마우스**

| 입력 | 결과 |
|---|---|
| 클릭(누른 뒤 약 3pt 이내로만 움직이고 뗌) | 뗄 때 HEX 복사. 확대경 라벨에 "복사됨"을 잠깐 표시하고, 패널의 "커서 위치 색"에 그 색을 남긴다. |
| 드래그(3pt 넘게 움직임) | 기존처럼 패닝. 패닝 중에는 확대경을 숨긴다. |
| 더블클릭 | **뷰어 닫기를 하지 않는다.** 연달아 빠르게 찍다가 뷰어가 닫히는 것을 막기 위해서다. 닫기는 ESC 또는 색상 버튼. |

⌥를 마우스를 누른 채 떼는 경우, 돋보기 여부는 **누른 시점** 상태로 판단한다.

## 4. 색 추출 알고리즘

1. **축소**: 원본을 긴 변 기준 수백 px(초기값 256px, 측정 후 조정)로 줄인 사본을 sRGB 8bit로 그린다. 목표는 1초 이내. 아주 작은 점의 색은 칩에서 빠질 수 있으며, 그런 색은 돋보기로 집는다.
2. **양자화**: 픽셀을 채널당 상위 5bit로 묶은 히스토그램을 만든다(최대 32768칸). 칸마다 개수와 **가장 많이 나온 실제 색**을 기록한다.
3. **Lab 변환**: 각 칸의 대표색을 CIE Lab(D65)으로 바꾼다.
4. **묶기**: 개수가 많은 칸부터 차례로, 이미 만든 묶음의 대표색과 **ΔE**가 허용 범위 이하이면 그 묶음에 합치고, 아니면 새 묶음을 만든다. 슬라이더 값이 이 허용 범위(ΔE)다.
5. **칩 색**: 묶음의 평균이 아니라 묶음 안에서 **가장 많이 나온 실제 색**이다. 평균은 이미지에 없는 탁한 색을 만들 수 있다.
6. **정렬**: 차지 비율 순.

- 히스토그램(1~3단계)은 이미지당 한 번만 만들고, 슬라이더를 움직일 때는 4~6단계만 다시 돈다. 그래야 실시간으로 바뀐다.
- 아주 적은 비율(예: 0.1% 미만)의 묶음은 칩에서 뺀다. 기준값은 구현하며 실제 이미지로 조정한다.
- ΔE 식(CIE76 또는 CIEDE2000)은 구현 단계에서 속도를 재고 정한다. 묶음 수가 많지 않아 CIEDE2000도 감당할 수 있을 것으로 본다.
- 계산은 백그라운드에서 하고, 이미지가 바뀌면 진행 중인 계산을 취소한다(기존 `loadGeneration` 패턴).

### 색 값 표기

- **HEX**: `#RRGGBB` 대문자. 복사 기본값.
- **RGB**: `231, 111, 81`.
- **CMYK**: ICC 프로파일 없는 단순 변환(참고용 근사값), 0–100 정수. 포토샵의 CMYK 값과 다를 수 있다. ICC 프로파일 기반 변환은 다음 단계에서 검토한다.
- 모든 값은 원본을 sRGB로 변환한 기준이다. 이미지에 다른 색 공간 프로파일이 있으면 sRGB로 바꾼 값을 보여준다.

## 5. 좌표 변환(가장 위험한 부분)

돋보기는 **화면에 보이는 그 픽셀의 원본 값**을 읽어야 한다. `ImageDisplayView`는 확대·축소·패닝·좌우/상하 반전·회전(`applyTransformedImage`)을 지원하므로, 다음 순서로 바꾼다.

1. 마우스 좌표(창) → 문서 뷰 좌표(배율·패닝 반영)
2. 문서 뷰 좌표 → 변형된 이미지의 픽셀 좌표
3. 변형된 이미지 좌표 → 반전·회전을 **거꾸로** 적용해 원본 픽셀 좌표
4. 범위 밖이면 "이미지 밖"으로 처리

- 픽셀 값은 화면에 그려진 결과가 아니라 **원본 비트맵**(sRGB 변환본)에서 읽는다. 확대 보간이나 화면 색 관리가 값에 섞이지 않게 하기 위해서다.
- 이 변환은 순수 함수로 분리해, 반전·회전·배율 조합별 테스트를 둔다.

## 6. 구조

| 구성 | 역할 |
|---|---|
| `ColorExtractionService` (services) | 축소·히스토그램·Lab·묶기. 입력: `CGImage`, 허용 범위. 출력: `[ColorSwatch]` |
| `ColorSwatch` (models) | `color`(sRGB), `ratio`, `lab`. AI 컬러 시스템의 입력으로 그대로 쓴다 |
| `ColorFormat` (models 또는 services) | HEX·RGB·CMYK 문자열 변환, sRGB↔Lab, ΔE |
| `ColorPalettePanel` (viewer) | 하단 패널: 슬라이더, 칩, 정보창, 커서 위치 색, HEX 전체 복사, 돋보기 토글 |
| `MagnifierOverlayView` (viewer) | 확대경과 HEX 라벨. `CropOverlayView`처럼 `scrollView` 위에 덧씌운다 |
| `ImageDisplayView` 확장 | 원본 픽셀 좌표 변환, 돋보기 모드의 마우스 처리(클릭/드래그 구분, 더블클릭 닫기 막기) |
| `ViewerViewController` | 색상 버튼, 패널 열고 닫기, ⌥ 감지(`flagsChanged`), 활성 조건 |

- 문자열은 기존 `Localization`을 쓴다.
- 복사는 `NSPasteboard.general`에 문자열로 넣는다.

## 7. 테스트

`Tests/`(기존 자체 러너)에 단위 테스트를 둔다.

- HEX·RGB·CMYK 변환(경계값: 검정, 흰색, 순색)
- sRGB→Lab 변환과 ΔE(알려진 기준값)
- 묶기: 허용 범위를 키우면 칩이 줄어든다, 칩 색이 이미지에 실제 있는 색이다, 비율 합이 100%다
- 좌표 변환: 반전(좌우·상하)·회전(0/90/180/270)·배율 조합에서 지정한 원본 픽셀을 읽는다
- 클릭/드래그 구분 임계값

수동 확인: 큰 이미지에서 추출 시간, 슬라이더 반응, ⌥ 단독/조합 키, 연속 클릭 시 뷰어가 닫히지 않음, 이미지 전환 중 패널 상태.

## 8. 다음 단계(이번 범위 밖)

- 팔레트 파일 내보내기: `.ase`(Adobe Swatch Exchange)는 포토샵·일러스트레이터 공통. 페인터·클립스튜디오가 가져올 수 있는 형식은 확인 필요.
- ICC 프로파일 기반 CMYK 변환.
- AI 컬러 시스템: `[ColorSwatch]`를 입력으로 메인/서브 색 지정, 칩 고정 선택 검토.
