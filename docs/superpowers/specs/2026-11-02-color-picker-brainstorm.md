# 색상 추출·돋보기 — 브레인스토밍 진행 기록 (미승인)

> 상태: **브레인스토밍 진행 중.** 승인된 설계 문서가 아니다. 다른 컴퓨터에서 이어갈 수 있도록 지금까지의 대화를 정리한 인수인계 기록이다.
> 다음 단계: 아래 "남은 질문"을 마저 정한 뒤, 이 파일을 정식 설계 문서(`…-color-picker-design.md`)로 옮겨 쓰고 승인을 받는다.

## 왜 만드는가 (사용자 확인)

- 드로잉 툴로 그림을 그리다가, jena-image에서 참고 이미지를 열어 마음에 드는 색을 **바로 확인하고 가져가려는** 용도.
- 지금은 다른 툴의 스포이드를 쓰려면 그 툴을 따로 띄워야 한다. 그 번거로움을 없애는 게 핵심.
- 확장 방향: 추출한 메인/서브 컬러로 **AI가 컬러 시스템을 만드는 기능**까지 생각하고 있음 → 이번 범위에서는 제외하고, 추출 결과가 나중에 그 입력으로 쓰일 수 있게 구조만 열어둔다.

| 칩 마우스 오버 | 칩 위쪽에 정보창(색 견본·HEX·RGB·CMYK, 값마다 복사 버튼). 마우스가 칩 또는 정보창 위에 있는 동안 유지 — 칩→정보창으로 옮겨가도 닫히지 않게. 정보창이 옆 칩을 가리지 않게 배치 | 사용자 (2026-11-02) |

| 돋보기 표시 | **③ 작은 확대경(픽셀 격자, 가운데 읽는 픽셀 강조) + HEX 한 줄**만 커서를 따라다님. HEX·RGB·CMYK 전체 값은 하단 서랍 왼쪽 "커서 위치 색" 칸에 고정 표시(시안 `docs/superpowers/mockups/2026-11-02-color-magnifier-style.html`) | 사용자 (2026-11-02) |

| ⌥ 임시 돋보기 | 패널이 닫혀 있어도 동작(이때는 확대경+HEX 한 줄만, 클릭 시 HEX 복사). 조건: 원본 로딩 완료된 이미지(동영상 제외), **⌥ 단독**일 때만(⌘⌥ 등 조합 키에선 켜지지 않음). 토글이 이미 켜져 있으면 ⌥는 변화 없음 | 사용자 (2026-11-02) |
| 토글 상태 | 패널을 닫으면 돋보기도 꺼짐, 다시 열면 꺼진 상태로 시작. 패널이 열린 채 다른 이미지로 넘어가면 켜진 상태 유지 | 사용자 (2026-11-02) |
| 돋보기 중 마우스 | 거의 움직이지 않고(약 3pt 이내) 떼면 HEX 복사(mouseUp 시점), 그 이상 움직이면 패닝. 패닝 중 확대경 숨김. **더블클릭 뷰어 닫기 비활성**(연속 클릭으로 뷰어가 닫히는 것 방지 — 닫기는 ESC·색상 버튼). 이미지 밖 여백·패널 위에선 확대경 숨김 | 사용자 (2026-11-02) |
| 결과 저장 | 이미지별 저장 안 함(재계산 1초 이내 목표, 경로 기준 저장은 이동·이름 변경 시 어긋남). 슬라이더 값만 앱 전체에서 마지막 값 기억 | 사용자 (2026-11-02) |
| 내보내기 | 이번 범위는 패널의 **"HEX 전체 복사"** 버튼 하나(비율 순, `#3F7CAC #E9C46A …` 형식). 팔레트 파일 내보내기는 다음 단계 — 사용 툴: 포토샵·페인터·클립스튜디오·일러스트레이터 | 사용자 (2026-11-02) |
| AI 연결 | UI 추가 없음. 추출 결과를 칩별 {색, 차지 비율, Lab} 목록 구조로 만들어 두어 AI 컬러 시스템의 입력으로 쓰게 함 | 사용자 (2026-11-02) |

## Claude 제안 — 사용자 확인 완료 (2026-11-02, CMYK는 근사값으로 진행하고 ICC 프로파일은 나중에 검토)

- 색이 비슷한지는 RGB 거리가 아니라 **Lab ΔE**(지각 거리)로 판단한다.
- 칩 색은 묶음의 평균이 아니라 **가장 많이 나온 실제 색**으로 한다(평균은 이미지에 없는 탁한 색을 만들 수 있음).
- 칩은 **차지 비율 순**으로 놓고 비율(%)을 함께 표시한다. AI 컬러 시스템의 메인/서브 판단 입력이 된다.
- 계산은 긴 변 기준 수백 px로 줄인 사본에서 한다(1초 이내 목표). 아주 작은 점 색은 빠질 수 있음.
- CMYK는 ICC 프로파일 없는 **단순 변환(참고용 근사값)**.
- 색상 버튼은 동영상일 때 숨기고, **원본 로딩이 끝난 뒤에만 활성화**한다(지금 편집 버튼과 같은 규칙. 썸네일 미리보기로 뽑으면 저해상도 값이 나옴).

## 코드 조사 결과

- 하단 버튼: `Sources/viewer/ViewerViewController.swift` `setupEditButton()` (약 410행). 오른쪽 아래부터 trailing 체인 `[카테고리][북마크][편집][썸네일 토글]`.
- 이미지 위 오버레이 선례: `Sources/viewer/CropOverlayView.swift`, `ImageDisplayView.showCropOverlay` — 돋보기도 같은 방식으로 `scrollView` 위에 덧씌우면 된다.
- `ImageDisplayView`는 확대·축소·패닝·좌우/상하 반전·회전(`applyTransformedImage`)을 지원한다. **마우스 좌표 → 원본 픽셀 좌표 변환이 가장 위험한 부분**(반전·회전·배율 상태에서 다른 픽셀을 읽으면 안 됨).
- 오른쪽에 썸네일 목록(`ThumbnailStripView`)이 있어 패널 위치와 겹침을 고려해야 한다.
