## 결정

### 축소 긴 변: 512px

| 긴 변 | 44.2MP 전처리 | 512 기준 상위 6색 HEX 정확 일치 |
|---|---:|---:|
| 512 | 80.2ms | 6/6 |
| 384 | 6.1ms | 3/6 |
| 256 | 3.8ms | 4/6 |
| 192 | 2.8ms | 2/6 |
| 128 | 2.1ms | 3/6 |

계획의 5/6 정확 일치 조건을 만족하는 후보가 512뿐이었다. 전처리 1000ms 예산에도 여유가 있어 256에서 512로 변경했다. 정확한 HEX 일치는 지각적 유사도보다 엄격하며, 512가 원본의 정답이라는 뜻은 아니다. 기준 팔레트 비교는 계획대로 CIE76/허용12/최소0.001이다. 6색 미만 표본의 로그 분모는 고정 6이므로 이 판정에 쓰지 않았다.

### 색 차이: CIEDE2000 / 최소 비율: 0.0005(0.05%)

- 실제 적용할 512px/최소0.0005/허용8~20 구간에서 CIEDE2000 묶기 중앙값은 최대 4.52ms로 16ms 기준 이하였다. 기본 허용12에서 big/photo 각각 2.60ms, render 1.66ms다.
- 일러스트 원본의 보라색 꽃과 파란 머리띠를 확인했다. 최소0.0005에서는 `#CFA1C7`(0.379%)와 `#B7C0D3`(0.314%)가 남는다. 0.001은 보라색을, 0.002는 둘 다 잃는다. 작은 포인트 색 보존을 우선해 0.0005를 택했다.
- 사진의 기본 칩 수는 15개로 유지된다. 투명 아이콘에서는 주요 파랑·흰색과 경계색 2개가 남는다. 낮은 기준에 따른 경계색 잔존은 포인트 보존과의 트레이드오프다.
- 현재 구현의 최소 비율은 **최종 묶음 필터뿐 아니라 새 묶음을 만드는 각 히스토그램 칸의 최소 비율**로도 작동한다. 따라서 최종적으로 0.1%를 넘을 색도 여러 작은 칸으로 분산되면 빠질 수 있다. 비율 합이 100% 미만일 수 있으며, 이번 작업은 알고리즘을 바꾸지 않았다. 작은 색을 정확히 집는 기능은 Task 4 이후 원본 픽셀 돋보기에서 제공한다.

Task 7의 AppSettings에 적용할 결정이며, 아직 설정·슬라이더 UI를 구현한 것은 아니다. 계획서 예시의 2...40은 이 값으로 대체한다.

- `PixelMapping`: 문서 좌표를 원본 픽셀로 역변환한다. 좌우/상하 반전·90도 단위 회전·포인트/픽셀 크기 차이를 반영하며, 이미지 밖은 nil이다. 배율·패닝 좌표 변환 헬퍼도 추가했다.

- 테스트를 먼저 추가해 미구현 주입점으로 컴파일 실패를 확인했다. 지연된 이전 이미지 결과 폐기, 슬라이더 재분류·저장, 패널 재열기 캐시 재사용, 전체 HEX 및 선택색 복사를 검증한다. 확정 범위 8...20에 맞춰 색상 표본을 수정했고 공유 카운터는 잠금으로 보호한다. 테스트 설정과 클립보드 항목은 원래 값으로 복원한다.

- 현재 pro 저장소만 변경했다. 수정 전 원본은 `/tmp/jena-task11-backup`에 보존했다.


## 후속 — Task 12 Option 임시 돋보기

- `flagsChanged`를 기존 OptionKeyGate에 연결했다. 패널이 닫혀 있어도 Option 단독일 때 픽셀 소스를 지연 준비하고 원본이 준비된 이미지에서만 돋보기를 켠다. 키를 떼거나 Command/Shift/Control과 조합하면 임시 상태를 해제한다.
- 뷰가 나타날 때 해당 창의 비활성화 알림을 관찰하고 임시 상태를 해제한다. 창이 없는 경우 전역 알림을 구독하지 않으며, 재진입·뷰어 이탈·해제 시 관찰자를 제거한다. 패널 토글로 켜진 상태는 창 비활성화에도 유지한다.
- 계획의 테스트를 먼저 추가해 Option 단독 활성화와 픽셀 준비 실패를 확인했다. 추가로 Shift/Control 조합, Option 유지 중 이미지 전환과 원본 준비 후 복귀, 창 비활성화 시 토글 유지, 뷰어 이탈 시 해제를 검증했다.
- `make build` 성공, `make test` 110개, `make test-ui` 81개 전체 통과. 컴파일 경고·오류 없음. 테스트는 합성 flagsChanged 이벤트와 창 알림을 사용했다. 실제 키보드 Option·Command-Tab 수동 검증은 Task 13에 남아 있다.
- 동작 변경 없는 테스트 파일 끝 빈 줄을 정리했고 `git diff --check`를 확인했다. 기존 코드와 사용자 변경을 보존하며 현재 pro 저장소만 수정했다. 변경 전 파일은 `/tmp/jena-task12-backup`에 보존했다.
