# AI 생성 이미지의 원본 기반 파일명

## 변경과 이유
참조 원본이 있는 생성 결과를 원본과 쉽게 연결할 수 있도록 저장 파일명만 변경했다.
- 참조 있음: 첫 번째 참조의 확장자를 제외한 이름 + `_AI.png`.
- 이름 충돌 또는 여러 결과: `_AI_2.png`, `_AI_3.png` 순서로 저장.
- 참조 없음: 기존 `AI-UUID.png` 유지.

## 결정과 절충
여러 참조와 생성 결과 사이에 일대일 대응 정보가 없으므로 첫 번째 참조 이름을 기준으로 삼는다. 복사 자체가 이름 충돌로 실패한 경우에만 다음 번호로 재시도하여 기존 파일을 덮어쓰지 않는다. 다른 저장 오류는 기존 부분 저장 오류 처리로 전달한다. CLI 실행·참조 전달·저장 폴더·UI 흐름은 변경하지 않았다.

## 검증
테스트용 CLI로 원본 이름 적용, 다른 확장자와 점이 포함된 원본명, 반복 생성, 여러 참조·결과, 기존 파일 내용 보존 및 참조 없는 UUID 저장을 검증한다. 실제 AI 호출은 파일명 규칙 검증에 필요하지 않아 실행하지 않았다.

결과: `make test`, `make build`, `git diff --check` 통과.
