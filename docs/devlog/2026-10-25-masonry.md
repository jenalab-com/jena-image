# 2026-10-25 — 이미지 목록 masonry 레이아웃

## 요청과 디자인

이미지 목록을 Pinterest처럼 높이가 다른 이미지가 열마다 이어지는 masonry로 변경하고,
모서리를 약간 둥글게 처리한다. 기존 이미지 관리 사용자가 원본 구도를 보며 탐색하도록
원본 비율을 유지하고 잘라내지 않는다. 파일명, 경로 줄, 북마크·영상 표시와 선택 기능은 유지한다.

- 기본 목표 열 폭 180pt, 셀 사이 간격 12pt, 이미지 모서리 8pt.
- 창 너비와 기존 썸네일 크기 슬라이더에 맞춰 열 수와 열 폭을 재계산한다.
- 폴더·북마크·카테고리에서 공통 레이아웃을 사용한다.
- 참고: [Pinterest Gestalt Masonry](https://github.com/pinterest/gestalt/blob/master/packages/gestalt/src/Masonry.tsx),
  [AppKit NSCollectionViewLayout](https://developer.apple.com/documentation/AppKit/NSCollectionViewLayout).
  기존 AppKit 색상·서체를 재사용하며 웹 컴포넌트를 도입하지 않는다.

## 구현

- `MasonryGeometry`: 순서대로 가장 짧은 열에 배치. 열별 y 위치 이진 검색으로 보이는 범위만 조회.
- `MasonryLayout`: NSCollectionView의 셀 재사용·선택·드래그·우클릭을 유지하는 커스텀 레이아웃.
- `ImageAspectRatioReader`: ImageIO로 픽셀 크기와 EXIF 방향만 읽고, 원본 전체 디코딩은 하지 않는다.
  기존 iCloud 미다운로드 판별을 먼저 수행해 다운로드를 유발하지 않는다.
- 비율 조회는 백그라운드에서 수행하고 묶어서 반영한다. 목록 전환 시 이전 작업은 취소하고
  세대 번호로 늦은 결과를 무시한다. 화면을 벗어날 때 취소하고 복귀 시 남은 조회를 재개한다.
- 스크롤 중 비율이 확정되면 보이던 항목의 위치를 기준으로 스크롤 위치를 보정한다.
- 이미지 비율을 읽지 못하면 임시 정사각형(영상은 16:9)을 쓰고, 썸네일이 도착하면 보완한다.
- 이미지 셀의 정사각형 제약을 제거하고, 아래쪽에 두 줄 파일명과 필요시 상대 경로 공간을 확보한다.
