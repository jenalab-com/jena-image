# 2026-10-26 — P2P 이미지 공유 설계 문서

## 배경

중계서버 없이 사용자가 지정한 폴더의 이미지를 다른 사용자가 다운로드하고, 공유 폴더 목록을 사이드바에서 탐색하는 기능을 검토했다. 구현에 앞서 연결 범위와 읽기 전용 경계를 문서로 확정하기로 했다.

## 변경

- `docs/p2p-sharing-design.md`에 제품 범위, 사용자 흐름, 화면, 모델, 아키텍처, 프로토콜, 보안, 테스트, 단계별 계획을 작성했다.
- `docs/plan.md`에 P2P 공유를 미착수 후속 항목으로 연결했다.
- `docs/design-log/2026-10-26-p2p-sharing.md`에 UI 방향과 대안을 기록했다.

## 주요 결정

- 1차 MVP는 Bonjour 기반 같은 로컬 네트워크로 제한하고 인터넷 직접 연결은 별도 검증으로 분리한다.
- 선택한 루트의 직속 이미지만 명시적으로 공유하며 기존 등록 폴더를 자동 공개하지 않는다.
- 원격 파일은 로컬 `ImageFile`과 분리하고, 업로드·삭제·이름 변경은 네트워크 명령으로도 정의하지 않는다.
- MVP는 원격 썸네일 탐색과 선택 원본 다운로드에 집중한다.

## 트레이드오프

- 서버리스는 운영 비용과 중앙 저장소를 없애지만 피어가 온라인이어야 하고 인터넷 NAT 환경의 연결 성공을 보장할 수 없다.
- 원격 전용 UI는 일부 중복이 생기지만 로컬 파일 조작이 원격 항목에 잘못 적용될 위험을 줄인다.
- 로컬 MVP는 빠르게 검증할 수 있지만 공개 커뮤니티에는 인증·암호화·악용 방지 설계가 추가로 필요하다.

## 검증

- 문서 작업만 수행했으며 앱 소스와 빌드 설정은 변경하지 않았다.
- 따라서 빌드·테스트는 실행하지 않았다.
- 실제 P2P 기능은 아직 구현되지 않았다.
