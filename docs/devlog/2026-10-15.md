# 2026-10-15 — 우클릭 "미리보기" + 썸네일 호버 확대

## 변경 사항

### `Sources/browser/BrowserViewController.swift`
- 우클릭 메뉴에 **미리보기** 추가(일반 보기: "열기" 아래, 이미지 1장 이상 선택 시 · 북마크 보기: 깨진 항목 없을 때).
  `showQuickLook()` → 기존 스페이스바 QuickLook 패널(`QLPreviewPanel`, 원본 해상도)을 연다. 이미 떠 있으면 현재 선택으로 이동.
- `collectionView.wantsLayer = true` — 호버 확대된 셀의 `zPosition`이 이웃 셀 위로 적용되도록.

### `Sources/browser/BrowserItem.swift`
- 썸네일 뷰에 `NSTrackingArea`(`.inVisibleRect`) → `mouseEntered/Exited`에서 `setHovered`.
- 레이어 `transform`을 1.2배로 0.15초 ease-out 애니메이션. AppKit 뷰 레이어 anchorPoint가 (0,0)이라
  `(1-s)·w/2` 평행이동을 합성해 중심 고정. 호버 중 `view.layer.zPosition = 1`.
- `prepareForReuse`·이름 편집 시작 시 즉시 원복(스크롤로 재사용될 때 mouseExited가 안 올 수 있음).

## 결정 사항

- "팝업으로 원본" 요구는 별도 팝오버를 새로 만들지 않고 **QuickLook 패널 재사용**. 이유: 이미 원본 해상도로 뜨고,
  ←/→ 순회·확대·전체화면이 공짜. 스페이스바와 메뉴가 같은 패널을 가리켜 동작이 일관됨.
- Dock의 "커서 위치에 따른 연속 확대"가 아니라 셀 단위 on/off 확대. 그리드 셀은 Dock 아이콘보다 커서 연속 배율은 산만함.

## 수동 GUI 검증 체크리스트

1. 이미지 우클릭 → "미리보기" → QuickLook 패널에 원본 표시. 여러 장 선택 후 → ←/→ 순회.
2. 북마크 보기에서도 "미리보기" 표시, 깨진 북마크 포함 시 비활성.
3. 썸네일 위에 마우스 올리면 0.15초 안에 1.2배 확대, 벗어나면 복원. 이웃 셀 위로 덮임(가려지지 않음).
4. 확대 중 빠르게 스크롤 → 재사용 셀이 확대 상태로 남지 않음.
5. 이름 편집(Enter) 중엔 확대 안 됨.
6. 선택 테두리·북마크 ★·비디오 ▶ 배지가 확대 시 같이 커지되 어색하지 않음.

# 2026-10-15 (추가) — 우클릭한 썸네일을 먼저 선택

- 문제: 우클릭 메뉴가 기존 선택(`selectedURLs()`)으로만 동작해, A를 선택한 채 B에서 우클릭 → 미리보기하면 A가 떴다.
- 수정: `DoubleClickCollectionView.menu(for:)` 오버라이드. 커서 아래 항목이 선택에 없으면 그 항목만 선택 후 메뉴 표시,
  이미 선택된 항목 위면 다중 선택 유지(Finder 동작). 빈 곳 우클릭은 선택 해제.
- 효과: 미리보기뿐 아니라 열기·이름 변경·삭제·북마크 등 모든 우클릭 메뉴가 커서 아래 항목을 대상으로 한다.
- 검증: A 선택 → B 우클릭 → 메뉴·미리보기가 B 기준. A·B 다중 선택 → A 우클릭 → 둘 다 유지(비교 메뉴 보임).
- `make build` — 경고·에러 0.

# 2026-10-15 (추가 2) — 사이드바 포커스 상태에서 미리보기가 빈 패널로 뜨는 문제

- 원인: `QLPreviewPanel`은 첫 응답자부터 응답자 체인을 타고 `acceptsPreviewPanelControl`을 구현한 객체를 찾는다.
  포커스가 사이드바 아웃라인에 있으면 체인이 `BrowserViewController`를 지나지 않아 dataSource가 없는 채로 열림 → "No selected item".
- 수정: `showQuickLook()`에서 `makeFirstResponder(collectionView)` 후 `panel.updateController()`로 컨트롤러 재탐색.
- 검증: 사이드바 폴더 클릭(포커스 사이드바) → 그리드 썸네일 우클릭 → 미리보기 → 해당 이미지가 뜸.
- `make build` — 경고·에러 0.
