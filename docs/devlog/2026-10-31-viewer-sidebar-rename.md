# 상세 우측 썸네일 비율과 이름 변경

## 변경
- 우측 썸네일의 120pt 폭(기존 80pt의 1.5배)을 적용하고 실제 썸네일 비율로 높이를 계산한다. 이미지 영역의 높이 제약과 테이블 행 높이를 함께 갱신한다.
- 캐시 적중과 비동기 완료 모두 같은 비율 갱신 경로를 사용한다. 셀 생성 중 재진입을 피하기 위해 행 높이 변경은 다음 메인 큐 실행으로 모은다. 파일명 영역은 기존 최대 3줄을 유지한다.
- 상세 이미지 우클릭에 이름 변경을 추가했다. 확장자를 제외한 이름을 편집하고 기존 MainWindow 파일 변경 처리로 연결한다. 파일 메뉴 이름 변경도 상세에서 사용할 수 있다.
- 변경 성공 시 현재 URL·창 제목·우측 목록 및 기존 북마크/카테고리 경로 갱신을 사용한다. 원본 로딩 중 변경하면 새 경로로 다시 요청한다. 취소는 파일을 변경하지 않는다. 이름 변경 직후 기존 폴더 새로고침이 상세를 닫는 문제도 확인해, 일반 목록 갱신을 상세에서 돌아오는 시점으로 미뤘다.

## 검증
가로/세로 썸네일의 실제 뷰와 행 높이, 캐시 재표시·선택 유지, 메뉴 → 입력창 → 실제 파일 이름 변경 → 상세 URL/제목 갱신 및 취소 흐름을 UI 테스트로 검증한다.

결과: make build 성공, UI 테스트 61개 및 git diff --check 통과. 기록: test/상세_썸네일_이름변경_2026-10-31/. 후속 요청에 따라 main에 커밋·푸시한다.

후속 디자인: 우측 썸네일에 6pt 둥근 모서리와 0.5pt 회색 테두리(불투명도 35%)를 적용했다. 이미지와 체크무늬를 함께 클리핑하고 기존 비율·행 높이는 유지한다.

썸네일 확대 후 레티나 요청 해상도는 240px(캐시 단계 330px), 목록 최소 폭은 160pt로 조정해 이미지 잘림을 방지했다.
