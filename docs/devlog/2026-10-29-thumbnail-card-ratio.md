# 썸네일 로딩 후 카드 비율 수정

## 원인과 변경
원본 메타데이터로 비율이 채워지면 비동기 썸네일의 실제 비율을 무시했다. 캐시 비율을 먼저 읽어도 늦게 도착한 메타데이터가 덮어쓸 수 있었다. 표시할 썸네일이 있는 URL을 추적해 썸네일 비율을 우선하고, 비동기 완료와 메모리 캐시 표시 경로 모두에서 카드 레이아웃을 갱신한다. 목록 전환 때 우선순위 상태도 초기화한다. 고정 정사각형 grid와 이미지 자체 투명 영역 표시는 유지한다.

## 검증
- 세로 원본 메타데이터와 지연된 가로 썸네일을 주는 공급자로 실제 NSCollectionView 카드와 이미지 뷰 프레임을 비교했다.
- 동일 테스트를 수정 전 BrowserViewController에 연결하면 비동기 로딩 및 캐시 재표시 2개 검증이 실패하고, 수정 후 모두 통과한다.
- make build 성공, 서비스 66개/UI 39개 통과, git diff --check 통과.
- 기록: test/썸네일_카드비율_2026-10-29/.
- 실제 문제 파일은 제공되지 않아 해당 파일 자체의 검증은 하지 않았다. 후속 요청에 따라 main에 커밋·푸시한다. 별도 릴리스는 생성하지 않는다.
