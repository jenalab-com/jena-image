# 상세 원본 대기 중 썸네일 불투명도 애니메이션

확대·블러 처리된 썸네일이 정지 상태로 오래 남아 로딩 실패처럼 보이던 문제를 개선했다. 미리보기 레이어에 불투명도 25 → 40 → 55 → 70 → 85 → 100%를 각 0.3초 간격으로 연결하고 역방향으로 되돌리는 왕복 애니메이션(상승 1.5초 + 하강 1.5초)을 추가했다. 타이머나 추가 이미지 디코딩 없이 Core Animation으로 처리한다. 실제 다운로드 진행률을 뜻하지 않는다.

원본 표시·오류·화면 정리의 공통 종료 경로에서 애니메이션을 제거한다. 다음 파일은 새 효과로 시작하며 원본·캐시 이미지의 픽셀과 편집 대상은 변경하지 않는다.

검증: UI 테스트로 단계·간격·반복 설정 및 성공/실패/취소 종료 시 효과 제거를 확인한다.

결과: make build 성공, UI 테스트 59개 및 git diff --check 통과. 로그: test/상세_로딩_불투명도_2026-10-31/. 후속 요청에 따라 main에 커밋·푸시한다.
