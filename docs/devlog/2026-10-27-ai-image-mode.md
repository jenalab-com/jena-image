# AI 이미지 생성 모드

## 변경과 이유
- 툴바 AI 버튼과 이미지 메뉴에 생성 작업 창 추가.
- 목록/뷰어 선택 이미지 가져오기, 참조 비우기, 프롬프트 입력과 폴더 선택 제공.
- Codex CLI 또는 JSON 계약 기반 사용자 지정 CLI를 백그라운드 실행.
- 참조 PNG 복사본, 작업별 디렉터리, 로그 파일, 출력 PNG 검증 및 UUID 파일명 저장.
- 실행 중 중복 요청 방지·취소·오류 표시·완료 미리보기와 Finder 결과 보기.
- 작은 창 스크롤 및 프롬프트의 복사/붙여넣기/전체 선택 연결.

## 결정·절충
기존 브라우저와 뷰어를 보존하는 별도 창을 선택했다. 모델·인증·이미지 생성 도구 설정은 CLI가 소유한다. 사용자 지정 CLI에는 JSON 계약 래퍼가 필요하다. 작업 파일은 자동 삭제하지 않는다. PNG 이외 출력과 생성 이력 UI는 포함하지 않는다.

## 검증과 발견 사항
- 테스트용 CLI로 참조 전달, 원본 보존, 반복 저장 충돌 방지, 비정상 종료, 빈 결과, 잘못된 이미지, 심볼릭 링크, 실행 전/실행 중 취소를 검증.
- URL 디렉터리 끝 슬래시 때문에 실패한 테스트는 실제 경로 비교로 수정.
- UI 테스트는 앞선 테스트 상태와 비동기 폴더 열거에 의존하지 않도록 자체 참조 파일과 목록 fixture를 사용.
- 실제 계정으로 이미지 생성은 실행하지 않았으며 Codex 도구 가용성은 검증되지 않았다.
- 최종 `make build`, `make test`, `make test-ui`, `git diff --check` 통과. UI 캡처: `.build/ai-mode-preview.png`.
