# 2026-11-13 — jena-image-pro를 공개 리포로 합침

## 배경

11-01에 공개(`jena-image`)/비공개(`jena-image-pro`) 리포를 나눴지만 유료 비공개 배포를 접기로 했다(작가 결정 11-13). 소스는 전부 공개(MIT)하고, 수익은 폴더 공유 링크 중계 같은 서버 서비스 구독과 공증·빌드 수고비 수준의 소액으로 간다. 두 리포를 동시에 유지하는 비용(히스토리 리라이트, 패치 이중 적용)이 이미 드러났으므로 하나로 합친다.

## 방법

- pro를 리모트로 추가해 공개 리포에 없던 pro 커밋 7개(`94f2ef3..2928036`: ColorPalettePanel·색 추출·임시 돋보기·사이드바 재설계·툴바 통일·검증 기록)를 **cherry-pick**으로 옮겼다. 공개 리포의 `014e66a`(색 추출 토대)는 pro의 `94f2ef3`와 사실상 같은 커밋이라 그 위에 얹었다. 충돌은 공개 리포에서 지워졌던 `docs/` 문서뿐이었고 전부 pro 쪽을 택했다.
- `docs/`(78개)·`scripts/`·`test/`(검증 로그)·`.gitignore`(`.superpowers/` 추가)·README를 pro에서 그대로 가져왔다. README의 스크린샷 경로가 `docs/media/`라 `assets/`는 제거(내용 동일, 중복 제거).
- **LICENSE는 MIT 유지**. pro의 독점 EULA는 가져오지 않았고 README 배지도 MIT로 되돌렸다.
- 양쪽에 미커밋으로 남아 있던 `make install` 기본 경로 `/Applications` 변경(11-03 devlog)도 함께 넣었다.
- 합친 뒤 `Sources`·`Tests`·`Resources`·`Info.plist`는 pro와 바이트 단위 동일.

## 검증

- `make build` 경고·에러 0, `make test`·`make test-ui` 통과.
