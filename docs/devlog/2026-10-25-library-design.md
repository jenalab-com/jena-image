# 라이브러리 디자인과 보기 방식 선택

## 요청

[사용자 참고 이미지](https://i.pinimg.com/1200x/c4/de/11/c4de111fd0966b2f10beb3923b275809.jpg)의
밝은 사이드바, 흐린 회색 반투명 캔버스, 둥근 카드 구성을 반영한다.
Masonry와 일반 격자를 선택할 수 있게 한다.

## 변경

- 사이드바 제목과 간격, 중립색 선택 행, 왼쪽 정렬 파일명과 둥근 카드(14pt)를 적용했다.
- 사이드바와 목록 배경에 서로 다른 네이티브 블러 재질과 반투명 색상을 적용했다.
  기존 스크롤 뷰의 불투명 배경을 없앴다. 배경 효과는 콘텐츠와 별도 뷰로 구성한다.
- 목록 오른쪽 상단에서 masonry / 일반 격자를 선택한다. 마지막 선택은 AppSettings에 저장한다.
- 격자는 같은 높이의 카드에 이미지를 원본 비율로 맞추며 행 순서로 배치한다.
  기존 가상화 레이아웃과 크기 슬라이더를 공유한다.
- 전환 시 현재 폴더·카테고리, 이미지 선택을 유지한다. 상세 화면에는 확대·맞춤 도구가 나타난다.
- 밝은 모드와 어두운 모드의 표면 색상을 각각 제공한다.

## 검증

- 단위 테스트 45개, UI 통합 테스트 22개: 총 67개 통과.
- `make build`와 `git diff --check` 통과.
- 실제 창 합성 캡처로 사이드바, 격자, masonry 및 다크 모드를 확인한다.
  일반적인 뷰 캐시 캡처에서는 macOS의 vibrant 사이드바 콘텐츠 일부가 누락되어,
  `JENA_CAPTURE_WINDOW=1 make test-ui`로 테스트 창 자체를 캡처할 수 있게 했다.
  기본 UI 테스트는 화면 밖에서 실행한다.
- 확인용 빌드와 캡처: `/tmp/jena-library-design.kMX2pU`.
- 테스트는 임시 이미지, 격리된 설정 저장소와 메모리 썸네일 공급자를 사용한다.
  실제 사용자 이미지·카테고리·북마크 데이터와 설치 앱은 변경하지 않는다.

## 후속 요청: 흰색 사이드바와 상세 배경

사이드바는 다크 모드에서도 불투명 흰색과 어두운 글자를 유지한다.
상세 화면의 기본 배경은 목록과 같은 네이티브 블러로 변경했다.
기존 설정의 밝은색·어두운색 단색 선택은 유지하며, 실제 사용자 설정은 변경하지 않았다.
투명 PNG 가독성은 검토만 진행했다. 흰 카드 위의 흰색 콘텐츠가 구분되지 않으므로,
이미지 영역에만 중간 회색 체크무늬를 화면 합성하는 방식을 권장한다.
체크무늬는 원본이나 썸네일 캐시에 굽지 않고 표시 단계에서 적용해야 한다.
썸네일 디스크 저장이 HEIC이므로 실제 적용 시 알파 보존 여부도 함께 검증해야 한다.
수정 전 백업: `/var/folders/jy/d4hl_blj2wgf55g7gg6nnz0m0000gn/T/jena-surfaces-backup-kuukhw8f/before.tar`.

## 후속 요청: 모든 이미지 썸네일의 체크무늬

투명 여부를 검사하지 않고 썸네일을 그리기 전에 8pt 회색 체크무늬를 표시한다.
목록, 상세 화면의 썸네일 목록, 비교 후보 썸네일에 공통 적용한다.
폴더 아이콘에는 적용하지 않으며 파일명 영역과 상세 원본 캔버스는 유지한다.
체크무늬는 화면에서만 그려 원본 이미지와 썸네일 캐시를 변경하지 않는다.
투명 영역의 두 톤과 불투명 흰색 픽셀의 보존을 래스터 테스트로 검증한다.
