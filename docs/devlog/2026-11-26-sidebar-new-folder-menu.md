# 사이드바 폴더 우클릭 메뉴에 "새 폴더" 추가

## 배경
- 사이드바에서 하위 폴더를 만들려면 폴더를 먼저 선택한 뒤 하단 `+` 버튼을 눌러야 했다.
- 폴더를 우클릭한 자리에서 바로 만들 수 있게 한다.

## 변경
- `SidebarViewController`: 우클릭 메뉴 맨 위에 "새 폴더" 항목 추가(`menuNewFolderTag`). 폴더 행에서만 보인다.
- `createNewSubfolder`에서 임시 행 삽입·이름 입력 부분을 `beginNewSubfolder(in:)`으로 분리해 `+` 버튼과 메뉴가 함께 쓴다.
- 메뉴 쪽은 선택된 행이 아니라 우클릭한 행(`clickedRow`)의 폴더를 부모로 삼는다.

## 결정
- 항목 이름은 하단 `+` 버튼의 레이블과 같은 "새 폴더"로 맞췄다.
- 생성 자체는 기존 `didRequestCreateFolder` delegate 경로를 그대로 탄다. 새 delegate는 만들지 않았다.
- 루트 폴더·하위 폴더 구분 없이 모든 폴더 행에서 보인다.

## 검증
- `make build` 경고·에러 0.
- [ ] 하위 폴더 우클릭 → "새 폴더" → 이름 입력 후 Return → 그 폴더 아래에 생성되는지.
- [ ] 선택된 폴더와 다른 폴더를 우클릭했을 때 우클릭한 쪽에 생기는지.
- [ ] 접혀 있던 폴더·빈 폴더에서도 펼쳐지며 입력 칸이 뜨는지.
- [ ] Esc로 취소하면 임시 행이 사라지는지.
- [ ] 이미지 행·그룹 헤더·북마크 행·카테고리 행에서는 항목이 보이지 않는지.
- [ ] 같은 이름이 이미 있을 때 오류 안내가 뜨는지.
