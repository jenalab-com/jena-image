# 2026-10-25 — 카테고리 이름 변경

## 요청과 변경

- 사이드바 카테고리 행 더블클릭 또는 우클릭 메뉴의 **이름 변경**으로 수정 창을 연다.
- 현재 이름을 미리 채우며, 변경/취소 버튼을 제공한다.
- 빈 이름과 다른 카테고리와 중복되는 이름은 입력을 유지하며 안내한다.
- UUID·지정 이미지·목록 순서는 보존하고 이름만 변경한다. 기존 변경 알림으로
  사이드바, 현재 카테고리 제목, 이미지 지정 메뉴를 갱신한다.
- 우클릭 메뉴는 현재 선택과 무관하게 우클릭한 카테고리 UUID를 보관한다.
- 폴더·파일의 기존 더블클릭 동작에는 개입하지 않는다.

## 결정

기존 추가 창과 같은 NSAlert 입력 방식으로 구현했다. 파일명 인라인 편집 로직과 섞지 않아
카테고리 이름 변경이 파일 시스템 작업으로 이어지지 않게 한다. 상세 화면에서 이름을
변경해도 상세 화면은 유지하고, 돌아왔을 때 바뀐 카테고리 이름을 표시한다.
