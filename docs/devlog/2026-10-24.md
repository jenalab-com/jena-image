# 2026-10-24 (추가) — Open With 구현 (v1.3 #19)

## 요청·배경
우클릭 메뉴에서 시스템에 등록된 호환 앱으로 파일을 열 수 있게 한다. 같은 메뉴에 "기본 앱으로 열기"도 둔다.

## 변경 사항
- [Sources/services/OpenWithService.swift](../../Sources/services/OpenWithService.swift) (신규)
  - `applications(for:)` — `NSWorkspace.urlsForApplications(toOpen:)`로 호환 앱 조회. 자기 자신(번들 경로·번들 ID) 제외, 번들 ID 기준 중복 제거, 이름순 정렬.
  - 앱 이름은 `CFBundleDisplayName` → `CFBundleName` → 파일명 순으로 결정(`.app` 제거).
  - 아이콘은 `NSWorkspace.icon(forFile:)`을 16×16으로.
  - `openWithDefault(_:)` / `open(_:withApplicationAt:)` — 전자는 `NSWorkspace.open`, 후자는 `open(_:withApplicationAt:configuration:)`.
- [Sources/browser/BrowserViewController.swift](../../Sources/browser/BrowserViewController.swift)
  - 일반·북마크 우클릭 메뉴의 "열기" 아래에 "다른 앱으로 열기" 하위 메뉴 추가.
  - 하위 메뉴: "기본 앱으로 열기" → 구분선 → 호환 앱 목록(아이콘 포함). 앱이 없으면 비활성 "사용 가능한 앱 없음".
  - `OpenWithTarget`(파일 URL + 앱 URL)을 `representedObject`로 실어 `contextOpenWith(_:)`에서 실행.
- [Sources/services/Localization.swift](../../Sources/services/Localization.swift): `openWith`·`openWithDefault`·`noCompatibleApps` 4개 언어 추가.
- [Sources/app/HelpWindowController.swift](../../Sources/app/HelpWindowController.swift): 브라우저 도움말에 항목 추가.
- [README.md](../../README.md)·[docs/plan.md](../../docs/plan.md): 기능 목록·19번 상태 갱신.

## 결정
- 대상은 **1개 선택 + 미디어 파일**. 여러 장 선택 시에는 메뉴를 띄우지 않는다(NSWorkspace 열기 API가 단일 파일 기준).
- 북마크 모드에서도 파일이 존재하면 같은 하위 메뉴를 제공한다.
- 앱 목록은 메뉴를 열 때마다 조회한다. LaunchServices 조회라 체감 지연은 없었다(하네스 기준 즉시).
- 더블클릭 동작(내부 뷰어)은 바꾸지 않고, "기본 앱으로 열기"를 메뉴 옵션으로 제공하는 쪽으로 해석했다.

## 검증
- `make build` 경고·에러 0.
- 서비스 단독 하네스(임시 main + `OpenWithService.swift`)로 JPG 조회: 앱 11개 반환, 자기 자신 없음, 이름에 `.app` 없음, 아이콘 16×16.
- 수동 GUI 확인 필요: 실제 메뉴에서 앱 선택 시 해당 앱으로 열리는지 · "기본 앱으로 열기"가 macOS 기본 앱으로 여는지 · 북마크 모드에서도 뜨는지 · 앱이 하나도 없는 확장자에서 "사용 가능한 앱 없음"이 보이는지.

## 트레이드오프
- 호환 앱 목록은 시스템 등록 기준이라 브라우저·뷰어 등 편집 앱이 아닌 앱도 포함된다. 필터링은 하지 않았다(사용자가 원하는 앱이 빠지는 것보다 낫다고 판단).
- 메뉴를 열 때마다 앱 목록을 새로 조회한다. 앱 설치/삭제가 즉시 반영되는 대신, 아주 느린 환경에서는 메뉴가 뜨기까지 약간 지연될 수 있다.


# 2026-10-24 (추가 2) — 이미지 정보 패널 구현 (v1.3 #20)

## 요청·배경
⌘I로 현재 이미지의 파일 정보·해상도·색 정보·EXIF·GPS를 한 창에서 확인한다.

## 변경 사항
- [Sources/services/ImageMetadataService.swift](../../Sources/services/ImageMetadataService.swift) (신규)
  - 파일 속성: 크기, 생성일, 수정일.
  - ImageIO(`CGImageSourceCopyPropertiesAtIndex`): 픽셀 크기, DPI, 색 모델, 색 프로파일, 포맷.
  - EXIF/TIFF: 카메라 제조사·모델, 렌즈, ISO, 셔터 속도, 조리개, 초점 거리(35mm 환산), 촬영일.
  - GPS: 위·경도(십진수, S/W는 음수), 고도(해수면 아래 표시).
  - 동영상은 ImageIO를 건너뛰고 파일 기본 정보만.
- [Sources/app/ImageInfoWindowController.swift](../../Sources/app/ImageInfoWindowController.swift) (신규)
  - 재사용 가능한 창(닫아도 컨트롤러 유지, `isReleasedWhenClosed = false`). 스크롤 가능한 선택 텍스트 — 값 복사 가능.
  - 메타데이터 조회는 `Task.detached`로 백그라운드에서 수행하고, 요청 토큰으로 최신 결과만 반영한다(iCloud 다운로드로 헤더 읽기가 느린 경우 대비).
  - 일반/이미지/카메라/위치 섹션. EXIF가 없으면 안내 문구, 동영상은 별도 안내.
- [Sources/app/MainWindowController.swift](../../Sources/app/MainWindowController.swift): 패널 보관, `showInfo(for:)`, `updateInfoPanelIfNeeded(for:)`.
- [Sources/app/MainWindowController+Actions.swift](../../Sources/app/MainWindowController+Actions.swift): `showImageInfo(_:)` + 메뉴 검증(미디어 1개일 때만).
- [Sources/app/MainMenu.swift](../../Sources/app/MainMenu.swift): 파일 메뉴 "정보 보기" ⌘I.
- [Sources/app/MainWindowController+Delegates.swift](../../Sources/app/MainWindowController+Delegates.swift): 브라우저 delegate, 뷰어 파일 이동 시 패널 갱신.
- [Sources/browser/BrowserViewController.swift](../../Sources/browser/BrowserViewController.swift): 우클릭 "정보 보기"(일반·북마크 모드).
- [Sources/services/Localization.swift](../../Sources/services/Localization.swift): 메뉴 라벨 4개 언어.
- [README.md](../../README.md)·[HelpWindowController.swift](../../Sources/app/HelpWindowController.swift)·[docs/plan.md](../../docs/plan.md)·[docs/architecture.md](../../docs/architecture.md): 기능·단축키·파일 트리 갱신.

## 결정
- 대상은 **미디어 파일 1개**. 여러 개 선택 시 메뉴가 비활성된다(패널이 한 파일 기준).
- 패널 문구는 앱 관습대로 한국어. 메뉴 라벨만 L10n을 태운다.
- 브라우저에서 선택만 바꿔도 자동 갱신하는 훅은 만들지 않았다. ⌘I를 다시 누르거나, 뷰어에서 파일을 이동하면 갱신된다.
- 포맷 이름은 `ImageFormat.displayName`을 우선해 JPEG·PNG처럼 짧게 표시하고, 미리보기 전용·동영상은 확장자 대문자를 쓴다.

## 검증
- `make build` 경고·에러 0.
- 서비스 하네스: 아이콘 JPG → 1024×1024, RGB, sRGB, 크기·날짜 정상.
- 합성 EXIF JPEG를 ImageIO로 만들어 재조회: 제조사/모델/렌즈/ISO 400/1-250초/f2.8/35mm(환산 52)/촬영일, GPS 37.566500, 126.978000/고도 38m 모두 표시 확인.
- 패널 단독 하네스로 창 생성·표시 확인(제목=파일명, 460×632), 크래시 없음. 렌더링된 텍스트에서 일반/이미지 섹션·JPEG·1.5 MB·1024×1024·sRGB·EXIF 없음 문구 확인.
- 수동 GUI 확인 필요: ⌘I로 패널이 뜨는지 · 브라우저 우클릭 메뉴 · 뷰어에서 ↑/↓로 넘길 때 갱신 · 동영상 선택 시 기본 정보 · 창을 닫았다 다시 열어도 동작하는지.

## 트레이드오프
- EXIF가 없는 이미지(스크린샷 등)는 카메라 섹션이 생략되고 안내 문구만 나온다.
- GPS 좌표는 텍스트라 지도 링크가 아니다. 필요하면 지도 앱으로 여는 버튼을 추가할 수 있다.
- 동영상은 해상도·코덱·길이를 아직 표시하지 않는다(추후 AVFoundation 연동).
