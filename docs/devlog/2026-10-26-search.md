# 2026-10-26 — 파일명 검색 (툴바 검색 필드)

## 요청

헤더(툴바)에 검색 입력 필드를 두고 파일명으로 검색, 결과는 "비슷한 이미지 찾기"처럼 별도 목록으로.

## 구현

- `app/MainWindowController+Search.swift`
  - `makeSearchToolbarItem()` — `NSSearchToolbarItem`(`ToolbarID.search`). 툴바가 모드 전환으로 다시 짜여도 같은 인스턴스를 돌려줘 입력한 글자가 남는다. `sendsWholeSearchString`로 Return에서만 검색, x·ESC는 `searchFieldDidEndSearching`에서 결과 닫기.
  - `searchFiles(matching:)` — 폴더 모드면 현재 폴더 트리를 `recursiveImages`(현재 정렬 기준 적용)로 `Task.detached` 열거 후 `folderLoadGeneration`으로 stale 결과 폐기. 북마크·카테고리·유사 목록이면 `listedImageURLs`를 `searchSourceURLs`에 보관해 그 안에서 거른다(결과에서 재검색해도 원래 목록 기준).
  - 매칭: 공백으로 나눈 낱말 전부 `localizedStandardContains`(AND, 대소문자·발음 부호 무시).
  - `SearchPresentation`에 출발 지점(카테고리/북마크/폴더)을 기억했다가 `closeSearchResults()`가 그리로 돌아간다. 유사 이미지의 `closeSimilarityResults`와 같은 규칙.
  - `clearSearch()`는 `navigateToFolder`·`showBookmarks`·`showCategory` 첫머리에서 `clearSimilaritySearch()` 옆에 호출. 필드 글자도 비운다.
- `BrowserViewController.isSearchMode` + `displaySearchResults(_:query:resetScroll:)`. `isCollectionMode`에 포함. 우클릭 메뉴는 유사 모드와 같이 "빼기" 없음·북마크 토글 있음.
- 모드 분기 추가: `refreshCurrentFolder`·`refreshAfterExternalChange`·`viewerDidRequestClose`(재검색), `toolbarBack`(닫기), 뒤로 버튼 표시·활성, ⌘V 붙여넣기 비활성.
- 편집 메뉴 "검색…" ⌘F → `focusSearchField` → `beginSearchInteraction()`. 다국어 키 `find` 4개 언어.
- 창 제목 "검색 · \"쿼리\" · 범위 · N개", 상태바 이미지 수.

## 결정

- 범위는 **현재 폴더 + 하위 폴더 전체**로 고정했다. plan의 "현재 폴더 / 전체 폴더" 토글은 두지 않았다 — 하위 폴더 포함 토글이 이미 사이드바에 있고, 검색은 Finder처럼 트리 전체가 자연스럽다. 루트 전체 검색은 루트를 선택하고 검색하면 된다.
- 즉시 검색(타이핑마다)은 두지 않았다. 폴더 트리 열거가 큰 폴더에서 수 초 걸릴 수 있어 Return 기준이 안전하다.
- 정렬은 검색 결과에도 그대로 적용된다(`recursiveImages`가 정렬해 돌려줌). 유사 모드처럼 정렬을 잠그지 않았다.

## 추가 수정 — 뷰어 복귀 시 스크롤 유지

- 증상: 검색 결과에서 뷰어로 갔다가 돌아오면 목록이 맨 위로 튀었다. `refreshSearchResults`가 폴더 범위 재검색을 `searchFiles`로 돌리는데, 새 검색과 같은 `resetScroll: true` 경로였다.
- 수정: `searchFiles(matching:resetScroll:)`에 매개변수를 두고 재검색(뷰어 복귀·파일 변경·정렬 변경)은 `false`. 새 검색(Return)만 맨 위로.
- 수동: [ ] 결과 스크롤 → 더블클릭 뷰어 → 더블클릭 복귀 → 스크롤 위치 유지.
