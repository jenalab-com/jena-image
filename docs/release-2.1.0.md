# JenaImage 2.1.0

## 주요 변경

### 웹 패널
- 툴바의 지구본 버튼(사이드바 토글 옆)으로 폴더 사이드바와 이미지 목록 사이에 웹 브라우저를 엽니다. 참고 이미지를 웹에서 찾아 보고 있는 폴더로 바로 모으기 위한 패널입니다.
- 웹 이미지를 **우클릭 → "'폴더'에 저장"** 하거나, **목록·폴더 타일·사이드바 폴더로 끌어다 놓아** 저장합니다. 저장하면 목록에 바로 나타나 선택됩니다.
- 탭을 지원합니다. 새 창으로 여는 링크와 로그인 창은 새 탭으로 열리고, ⌘클릭·가운데 클릭은 뒤에서 열립니다. 앱을 다시 켜면 열어 둔 탭이 돌아옵니다.
- 주소창에 검색어를 넣으면 Google·Bing·네이버의 웹 또는 이미지 검색으로 갑니다(기본은 Google 이미지 검색).
- 이미지를 끌어서 넘기는 화면처럼 사이트가 끌기를 막는 곳에서도 이미지를 끌어 저장할 수 있습니다.
- 뒤에 있는 탭과 접어 둔 패널의 페이지는 소리가 멈추고 알림창을 띄우지 못합니다.
- 저장할 이미지는 사용자가 실제로 우클릭하거나 끈 것만 받습니다. 웹 페이지가 스크립트로 흉내 낸 신호는 무시합니다.

### 앱 안에서 업데이트
- **JenaImage → 업데이트 확인…** 에서 최신 릴리스의 변경 내용을 보고 설치할 수 있습니다. 내려받은 파일의 크기·SHA-256과 앱의 번들 ID·버전을 확인한 뒤 앱을 교체하고 다시 실행합니다. 교체에 실패하면 이전 앱으로 되돌립니다.
- 이 기능은 2.1.0부터 들어 있으므로, 2.0.x에서는 이번 한 번만 DMG로 직접 설치해야 합니다.

### 고친 것
- **클라우드 폴더에서 삭제가 되지 않던 문제**: Google Drive 같은 폴더의 파일은 macOS가 앱의 휴지통 이동을 허용하지 않습니다(전체 디스크 접근 권한이 있어야 합니다). 이제 "바로 삭제할까요?"를 물어 확인하면 지웁니다. 취소가 기본 버튼이고, 폴더는 이 방식으로 지우지 않습니다. 삭제에 실패하면 어떤 파일이 왜 안 지워졌는지 알려 줍니다.
- 목록에서 파일을 폴더 타일 위에 놓아 옮기는 기능이 1.9.0 이후 동작하지 않던 것을 고쳤습니다.
- 뷰어에서 삭제를 취소하거나 실패해도 보던 이미지가 화면에서 빠지던 것을 고쳤습니다.

## 알아 둘 점
- 웹 패널의 로그인·쿠키는 JenaImage 안에만 저장됩니다(Safari와 공유하지 않습니다).
- 영상, 광고 프레임에 가린 이미지, CSS 배경·`blob:` 이미지는 저장할 수 없습니다.
- 클라우드 폴더에서 "바로 삭제"한 파일은 이 Mac의 휴지통에 들어가지 않습니다. 휴지통으로 보내려면 시스템 설정 → 개인정보 보호 및 보안 → 전체 디스크 접근 권한에 JenaImage를 추가하세요.

## 설치
- macOS 14 이상 / Apple Silicon(arm64)
- 첨부된 `JenaImage.dmg`를 열고 앱을 Applications 폴더로 복사하세요.
- 앱은 ad-hoc 서명되었으며 Apple 공증은 받지 않았습니다. 처음 실행이 차단되면 시스템 설정 → 개인정보 보호 및 보안에서 ‘그래도 열기’를 선택하세요.

## 검증
- 서비스 테스트 129개 및 UI 통합 테스트 173개 통과
- 웹 이미지 끌어다 놓기·우클릭 저장·탭 전환은 실제 마우스 이벤트로 조작해 확인했습니다(README의 데모 영상).
- 실제 사이트의 로그인 창(새 탭으로 열렸다 닫히는 흐름)과 전체 디스크 접근 권한을 준 뒤의 휴지통 이동은 확인하지 못했습니다.
- 배포 빌드, 앱 번들 서명 및 DMG 검증 완료
