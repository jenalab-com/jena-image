# AI 이미지 생성

## 설정에서 CLI 연결

**JenaImage → 설정… → AI 연결**에서 Codex CLI 상태를 확인한다.

- CLI가 없으면 **설치** 버튼으로 공식 설치 스크립트를 터미널에서 실행한다.
- 설치되어 있고 로그인되지 않았으면 **로그인** 버튼으로 `codex login`을 터미널에서 실행한다.
- 연결되면 CLI가 반환한 ChatGPT 이메일·요금제를 표시한다. API 키 인증은 키 값을 표시하지 않고 이메일이 제공되지 않음을 알린다.
- **재확인**은 실행 파일을 다시 찾고 `app-server`의 `account/read`로 인증 상태를 다시 조회한다. 이미지 생성이나 모델 프롬프트를 전송하지 않는다.
- 기본 경로는 `codex`다. PATH·Homebrew·사용자 설치 경로·nvm을 탐색하며, 직접 입력한 절대 경로도 지원한다. 실행 파일 설정은 앱 재시작 후에도 유지한다.

공식 근거: [Codex CLI 설치](https://learn.chatgpt.com/docs/codex/cli), [App Server 계정 조회](https://learn.chatgpt.com/docs/app-server). 로그인 자격 증명은 CLI가 관리하고 앱은 인증 파일을 직접 읽거나 복사하지 않는다.

## 오른쪽 AI 채팅

툴바 **AI** 또는 **이미지 → AI 이미지 생성…**을 누르면 오른쪽 사이드바가 열린다. 같은 버튼이나 패널의 닫기 버튼으로 접는다. 생성 중에도 패널을 접을 수 있으며 생성은 계속된다. 구분선을 드래그해 너비를 조절한다.

1. 왼쪽에서 결과를 저장할 실제 폴더를 선택한다.
2. 이미지 목록에서 파일을 선택하면 입력창 위에 참조 썸네일이 추가된다. 썸네일의 ×로 개별 제거한다. 입력창의 **+**로 이미지 파일을 추가할 수도 있다. 참조 없이도 생성할 수 있다.
3. 하단 입력창에 설명을 입력하고 **Enter**로 전송한다. **Shift+Enter**는 줄바꿈이며 한글 조합을 확정하는 Enter는 전송하지 않는다.
4. 생성 결과를 **전송 시점에 선택된 폴더**에 자동 저장한다. 참조가 있으면 첫 번째 참조의 확장자를 제외한 이름 뒤에 `_AI`를 붙여 `원본이름_AI.png`로 저장하고, 같은 이름이 있으면 `_AI_2.png`, `_AI_3.png`처럼 번호를 붙인다. 참조가 없으면 기존 `AI-UUID.png` 형식을 사용한다. 대화에 파일명과 이미지를 표시한다. **저장된 이미지 보기**를 누르면 앱의 상세 뷰어로 열린다. 결과가 여러 장이면 상세 뷰어에서 해당 결과들을 넘겨 볼 수 있다. 생성 중 다른 폴더로 이동해도 진행 중인 요청의 저장 위치는 바뀌지 않는다.
5. 생성 결과는 다음 요청의 참조로 첨부된다. 수정 설명을 이어서 입력하거나 참조를 제거해 새 이미지를 만든다.

입력창의 **⋯**에서 자동 저장 폴더를 확인하고 AI 연결 설정을 연다. 생성 중에는 입력창 안에 진행 표시와 **중지** 아이콘이 나타난다. 전송 버튼은 따로 두지 않는다. 긴 입력은 높이가 늘어난 뒤 내부 스크롤로 이어지며, 첨부 썸네일은 입력창 바로 위에 가로로 나열한다.

별도 저장 폴더 선택 버튼은 없다. 북마크·카테고리·검색 결과 같은 가상 목록에서는 실제 저장 폴더를 먼저 선택해야 한다. 제거한 참조는 동일 선택의 재통지로 다시 붙지 않으며, 목록에서 선택 해제 후 다시 선택하면 재첨부된다. 새 선택은 기존 첨부에 추가된다.

내 메시지는 오른쪽 말풍선, 결과와 오류는 별도 메시지로 표시한다. 최근 대화 12개 메시지의 텍스트와 현재 첨부를 다음 요청에 전달한다. 대화·첨부는 창 안에서 유지하며 앱 재시작 시 복원하지 않는다.

## 실행과 복구

앱은 Codex `exec --sandbox workspace-write`에 참조 PNG 복사본과 설명을 전달한다. CLI에 이미지 생성 도구가 설정되어 있어야 한다. 로그인 확인은 이미지 생성 도구의 가용성까지 보장하지 않는다.

기존 PNG 검증·원본 보존·실패 기록 보존은 유지한다. 저장 파일명이 겹쳐도 기존 파일을 덮어쓰지 않는다. 출력 없는 성공 종료, 손상 이미지, 심볼릭 링크는 실패로 처리한다. **중지**는 로컬 CLI 프로세스에 종료를 요청하고 2초간 응답하지 않으면 해당 프로세스를 강제 종료한다. 원격 작업과 모든 자식 프로세스의 종료를 보장하지는 않는다.

실패 메시지에는 작업 폴더가 표시된다. 설명과 참조를 복구해 다시 시도할 수 있다. 과거 성공 결과는 과거 메시지로 남고 새 실패를 성공으로 표시하지 않는다.

검증: CLI 계정 조회는 실제 설치된 Codex로 확인했다. 생성 파일 처리와 화면 동작은 테스트용 CLI/응답으로 검증하며 실제 계정으로 새 이미지를 생성한 검증은 포함하지 않는다.


### 채팅 모델 선택
입력창 안의 모델 버튼을 누르면 연결된 CLI의 사용 가능한 모델 목록을 불러온다. 선택한 모델을 기억하고 다음 생성 요청에 사용한다. ‘기본 모델’은 CLI 설정을 따른다. 이미지 참조를 지원하는 모델만 표시하며, 목록 조회에 실패하면 연결 설정을 확인한 뒤 버튼을 다시 눌러 재시도할 수 있다. 생성 중에는 선택을 잠근다.

이 선택은 Codex의 요청 처리 모델을 지정한다. 실제 이미지 생성 도구 내부의 이미지 모델과는 구분된다. 목록 형식은 [공식 App Server model/list 문서](https://learn.chatgpt.com/docs/app-server)를 따르며 모델명을 하드코딩하지 않는다.


### 생성 대기 표시
입력창의 + 버튼은 제거했다. 이미지 목록에서 선택한 파일이 입력창 위에 첨부되는 흐름은 유지한다. 생성 요청을 보내면 대화 마지막에 로딩 아이콘과 “이미지를 만들고 있어요..”를 표시하고 해당 위치로 스크롤한다. 성공·실패·취소 종료 시 대기 표시를 숨긴다. 중지 버튼은 입력창 안에 유지한다.


### 사용 현황
입력창 아래에 CLI 계정의 한도별 사용 비율과 리셋까지 남은 시간을 표시한다. 예: `5시간 · 사용 25% · 리셋 3h 20m`, `주간 · 사용 35% · 리셋 2d 3h`. 24시간 이상이면 d/h, 미만이면 h/m 형식이다. 채팅 표시 시와 생성 종료 후 및 표시 중 1분마다 갱신한다. 사용량이나 리셋 시각이 제공되지 않으면 정보 없음으로, 조회 실패는 확인 불가로 표시한다. 이는 앱만의 사용량이 아니라 연결된 CLI 계정의 한도다.

사용 필드는 [공식 App Server 사용량 문서](https://learn.chatgpt.com/docs/app-server)의 `account/rateLimits/read`, `usedPercent`, `windowDurationMins`, `resetsAt`(Unix 초)이며 여러 한도는 `rateLimitsByLimitId`를 우선한다.

사용 현황 오른쪽의 재조회 아이콘을 누르면 즉시 다시 조회한다. 조회 중에는 버튼을 비활성화하고 성공·실패 후 다시 활성화한다. 기존 자동 갱신은 유지한다.
