# AI 이미지 생성

이미지 목록에서 원하는 이미지를 선택한 뒤 툴바의 **AI** 또는 **이미지 → AI 이미지 생성…**을 연다. 선택 없이 설명만으로도 생성할 수 있다.

1. 연결 방식과 실행 파일을 지정한다. `codex`는 PATH와 Homebrew 기본 경로에서 찾는다. 다른 위치는 절대 경로를 입력한다.
2. 참조 목록을 확인한다. 원래 창에서 선택을 바꾼 뒤 **목록 선택 가져오기**로 갱신하거나 **참조 비우기**로 제외한다.
3. 이미지 설명을 입력하고 저장 폴더를 확인한다. 최초 위치는 현재 탐색 폴더이며 **저장 폴더 선택…**으로 변경한다.
4. **이미지 생성**을 누른다. 생성 중에는 입력 변경이 잠긴다. 완료 후 **결과 보기**가 Finder에서 저장 파일을 선택한다.

저장 파일은 `AI-UUID.png`이며 기존 이미지를 덮어쓰지 않는다. 생성 중 창을 닫으려면 완료를 기다리거나 명시적으로 취소한다. 취소는 해당 CLI 프로세스에 종료를 요청한다. 별도 서버·원격 작업을 취소하는 기능은 아니다.

## Codex CLI

CLI 로그인과 이미지 생성 도구가 미리 설정되어 있어야 한다. 이미지 입력 옵션만으로 이미지 생성 능력이 생기는 것은 아니다. 앱은 `codex exec --skip-git-repo-check --sandbox workspace-write --color never -C 작업폴더 --image 참조복사본 ... -- 프롬프트`를 실행한다. 생성 도구가 없거나 인증·네트워크 오류로 이미지가 나오지 않으면 성공으로 처리하지 않는다.

[공식 Codex CLI 명령 문서](https://learn.chatgpt.com/docs/developer-commands?surface=cli)를 참고한다. 이 개발 환경에서는 로컬 `codex exec --help`로 사용 옵션을 확인했다.

## 사용자 지정 CLI 계약 (v1)

이미지 생성 CLI를 호출하는 실행 파일 또는 실행 권한이 있는 래퍼를 지정한다. 셸 명령 전체를 입력하는 칸은 아니다. 앱은 실행 파일에 아래 JSON 파일의 **절대 경로 하나**를 인자로 전달한다. 표준 입력은 닫혀 있으며 대화형 인증은 별도로 완료해야 한다.

```json
{
  "version": 1,
  "prompt": "생성할 이미지 설명",
  "reference_images": ["/작업폴더/reference-1.png"],
  "output_directory": "/작업폴더/output"
}
```

래퍼는 JSON을 읽어 해당 CLI의 프롬프트·이미지 옵션으로 전달한다. 참조 없는 요청은 빈 배열이다. 출력 디렉터리 바로 아래에 완성된 PNG를 저장하고 성공 시 종료 코드 0, 실패 시 0 이외를 반환한다. 심볼릭 링크·잘못된 이미지·빈 결과는 거부한다. stdout/stderr는 작업 폴더의 `cli.log`에 기록된다.

예를 들어 [공식 OpenAI CLI](https://developers.openai.com/api/docs/libraries/openai-cli)의 `images generate`/`images edit`를 연결할 때는 JSON 응답의 `b64_json`을 디코딩해 출력 디렉터리에 PNG로 저장하는 래퍼가 필요하다. 앱은 CLI를 자동 설치하거나 인증 정보를 저장하지 않는다. GUI 앱에서 실행하므로 셸 초기화 파일은 읽지 않는다.

## 오류와 복구

실패 메시지에 작업 폴더 경로가 표시된다. 프롬프트, 참조 복사본, 결과와 로그가 남으므로 내용을 확인할 수 있다. 작업 폴더는 OS 임시 디렉터리에 있으며 앱에서 자동 삭제하지 않는다. 저장 중 일부 파일만 성공한 경우 저장 개수를 알리고 이미 저장한 파일과 나머지 작업 결과를 보존한다.

검증 범위: 테스트용 CLI를 사용한 연결·파일 처리와 UI 연결. 실제 계정으로 유료 이미지 생성을 실행한 검증은 포함하지 않는다.
