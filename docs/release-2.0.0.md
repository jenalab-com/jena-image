# JenaImage 2.0.0

## 주요 변경
- AI 이미지 생성을 우측 채팅 사이드바로 통합했습니다. 이미지 목록에서 선택한 파일을 참조로 첨부하고 개별 제거할 수 있습니다.
- 입력창에서 모델을 선택하며 Enter로 전송, Shift+Enter로 줄바꿈합니다. 생성 중에는 대화에 로딩 표시와 중지 기능을 제공합니다.
- 결과는 요청을 보낸 시점의 선택 폴더에 자동 저장합니다. 채팅에 파일명을 표시하고 앱 상세 보기에서 열 수 있습니다.
- 설정에서 Codex CLI 설치·로그인·연결 재확인 및 연결 계정 확인을 지원합니다.
- 채팅 하단에 사용량과 리셋까지 남은 시간, 자동 갱신과 수동 재조회 버튼을 제공합니다.
- 헤더와 채팅 제목이 겹치는 문제를 수정했습니다.

## 설치
- macOS 14 이상 / Apple Silicon(arm64)
- 첨부된 `JenaImage.dmg`를 열고 앱을 Applications 폴더로 복사하세요.
- 앱은 ad-hoc 서명되었으며 Apple 공증은 받지 않았습니다. 처음 실행이 차단되면 시스템 설정 → 개인정보 보호 및 보안에서 ‘그래도 열기’를 선택하세요.

## 검증
- 서비스 테스트 64개 및 UI 통합 테스트 38개 통과
- 실제 Codex 계정·모델·사용량 조회 확인
- 이미지 생성 요청·저장·상세 보기 흐름은 테스트용 CLI로 검증했으며, 실제 이미지 생성 엔진 호출은 검증하지 않았습니다.
- 배포 빌드, 앱 번들 서명 및 DMG 검증 완료
