# AI 연결 설정과 채팅 사이드바

## 문맥과 가정
단일 사용자 macOS AppKit 앱이다. 사용자는 CLI 연결을 설정에서 관리하고 현재 탐색 폴더로 결과를 자동 저장한다. 기존 CLI 실행·PNG 검증 서비스를 유지한다.

## 결정
- 연결: AIConnectionService가 실행 파일 탐색과 Codex App Server 계정 조회를 수행한다. AppSettings에는 실행 파일 경로만 저장한다. 조회 결과는 설정 화면의 일시 상태이며 인증 토큰은 소유하지 않는다.
- 설정: 별도 AI 연결 탭에 설치/로그인/재확인과 계정 표시를 둔다. 설치·로그인은 사용자 버튼으로 시작되는 Terminal .command다. 미설치, 미로그인, 연결, 조회 실패를 구분한다.
- 채팅: AIChatViewController를 메인 NSSplitViewController의 세 번째 항목으로 유지한다. 중앙 브라우저/뷰어 교체는 인덱스 1만 대상으로 한다. 패널 접기는 작업 취소가 아니다.
- 첨부: 브라우저 선택 이벤트의 새 항목을 추가한다. 첨부에서 제거한 항목은 선택 해제/재선택 전까지 반복 이벤트로 복구하지 않는다.
- 저장: 전송 시 MainWindowController의 실제 폴더를 값으로 캡처한다. 가상 목록에서는 전송을 막는다. 생성 중 이동은 다음 요청의 대상만 바꾼다.
- 대화는 창 상태, 실행 경로는 앱 설정, 인증은 CLI가 원본이다. 생성 파일은 선택 폴더가 원본이며 작업 로그는 기존 임시 디렉터리에 보존한다.

## 대안과 절충
기존 팝업/폴더 선택 방식은 새 요구와 맞지 않아 제거했다. 계정 표시를 위해 auth.json을 해석하는 대신 공식 account/read를 사용한다. 계정 조회는 시간 제한과 취소를 적용하며 오래된 조회 응답은 화면에 반영하지 않는다. 프로세스별 로그를 비공개 임시 파일로 읽어 파이프 정체를 피하고 조회 후 삭제한다.

사용자 지정 CLI 계약은 내부 생성 서비스/테스트에는 남지만 새 설정 UI의 연결 대상은 기존 기본값인 Codex다. 모델별 옵션과 영구 대화 저장은 추가하지 않았다. 실제 생성 도구 가용성은 별도 통합 검증이 필요하다.
