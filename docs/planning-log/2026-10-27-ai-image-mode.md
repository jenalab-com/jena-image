# AI 이미지 생성 모드

## 문제와 목표
이미지 목록에서 선택한 참조와 생성 설명을 CLI에 전달하고 결과를 원하는 폴더에 저장한다. 성공 기준은 정상 CLI fixture에서 선택 참조 전달 및 결과 저장 100%, 오류·빈 결과의 성공 오표시 0건, 원본 변경 0건이다.

## 가정과 선택
- 사용자는 로컬 이미지 라이브러리와 설치·인증된 AI CLI를 사용한다.
- Codex의 이미지 입력 지원은 이미지 생성 도구의 사용 가능성을 보장하지 않는다. 도구가 없으면 파일 미생성 오류를 표시한다.
- 기존 목록을 보며 참조를 바꿀 수 있도록 독립 작업 창을 사용한다. 기존 브라우저/뷰어 전환 구조는 보존한다.
- 기존 AppKit 컨트롤·시스템 폰트·색상을 재사용하는 기능 중심 디자인이다. 새 디자인 토큰은 도입하지 않는다.
- 직접 API 연결과 CLI 연결을 비교하여 요청대로 CLI를 선택한다. 다른 CLI는 명시적인 JSON 계약을 구현하는 실행 파일로 연결한다.

## 흐름과 수용 기준
이미지 선택 → 툴바 AI 또는 이미지 메뉴 → 참조 목록 확인 → 설명 입력 → 저장 폴더 확인·변경 → 생성 → 결과 보기.
- 선택 없이도 설명만으로 생성한다. 비디오를 참조로 보내지 않는다.
- 입력 누락은 실행 전에 안내하고 기존 입력을 유지한다.
- 실행 중 중복 제출 및 요청 변경을 막고 취소 버튼을 제공한다.
- 설치·인증·네트워크·쓰기 권한 오류와 실제 이미지가 없는 성공 종료를 실패로 표시한다.
- 결과 PNG를 검증하고 고유 파일명으로 저장해 기존 파일을 보존한다.

## 절충과 보류
PNG 출력만 지원한다. 여러 이미지 출력은 지원하지만 CLI별 모델·해상도·비율 설정과 대화 이력은 범위 밖이다. 참조는 현재 선택을 가져오는 방식이며 드래그 편집은 보류한다. CLI 비용 및 계정 권한은 해당 CLI 설정을 따른다.
